# Taskflow

Taskflow - quản lý công việc. Xây dựng bằng React + Vite.

## Bắt đầu

```bash
npm install
npm run dev      # chạy môi trường phát triển
npm run build    # build production
npm run lint     # kiểm tra mã nguồn
```

## Cấu trúc

- `src/App.jsx` – state chính (danh sách công việc, bộ lọc, lưu `localStorage`)
- `src/components/TaskForm.jsx` – form thêm công việc
- `src/components/TaskList.jsx` – danh sách công việc
